# Página personal con calculadora

Tarea 1 de Aplicaciones Web (UNIANDES, sexto semestre).

Es mi página personal hecha con HTML y CSS, y dentro tiene una calculadora hecha en PHP que permite sumar, restar, multiplicar y dividir.

## Archivos
- `index.php`: la página con mi información y la calculadora
- `style.css`: los estilos de la página

## Cómo ejecutarlo
1. Copiar la carpeta en `C:\xampp\htdocs\`
2. Encender Apache desde XAMPP
3. Abrir `http://localhost/Personal_VilelaKaren/index.php`
